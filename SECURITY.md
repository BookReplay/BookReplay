# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue. Use **Report a vulnerability** under this repository's *Security* tab (GitHub private vulnerability reporting). Include the version or commit you tested, how to reproduce the problem, and what an attacker could gain.

You should get a first reply within a week. Please give the maintainer reasonable time to ship a fix before publishing details.

## Supported versions

Only the latest released version receives security fixes. Before the first release, that means the `main` branch.

## Operating an instance safely

The operator guide in [deploy/SECURITY.md](deploy/SECURITY.md) covers HTTPS, the setup secret, password recovery and the limits of the built-in rate limiter.
